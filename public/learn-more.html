03 / How it works

A private handoff, step by step.

SealBox combines fast file encryption with recipient-specific key protection, all inside your browser.

01

A one-time file key

A fresh random AES-256-GCM key encrypts the file contents and detects changes to the ciphertext.

02

Recipient key protection

RSA-OAEP with SHA-256 wraps the one-time key using the recipient’s public key.

03

A portable package

The encrypted file and key information are bundled into a .sealbox file for sharing and later decryption.

04 / Security

Protection built into the workflow.

Encryption happens locally, and the package is designed so the intended recipient can recover its contents with the matching private key.

✓

Authenticated encryption

AES-256-GCM protects file contents and reports if encrypted data has been altered.

✓

Private keys stay yours

Your private key is used in your browser to decrypt. Share public keys; keep private keys secret.

✓

No plaintext upload

SealBox performs file encryption and decryption in your browser rather than uploading plaintext to a server.

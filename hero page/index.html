SealBox encrypts files in your browser for a specific recipient. Download a portable package and share it through a channel you trust.

Encrypt a file How it works

Private by design

Files are encrypted in your browser before you download or share them. Plaintext stays on your device.

Recipient-only access

A one-time AES key encrypts the file. The recipient's RSA public key wraps that key for decryption with the matching private key.

Simple file sharing

Create a portable .sealbox package locally, then send it with the email, chat, or storage service you already trust.

Files sealed for the people who should see them

Your file is encrypted locally before it leaves your device. A one-time AES key protects its contents, and the recipient's RSA public key wraps that key. Choose a file, select the recipient's public key, and download the encrypted .sealbox package. Only the matching private key can decrypt it.
